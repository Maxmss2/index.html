# VÍDEOCREATOR Video Worker

Worker Docker para geração de vídeos, baseado na imagem oficial do Automated Video Generator.

## Deploy no Render

- Tipo: Web Service
- Repositório: Maxmss2/index.html
- Runtime: Docker
- Root Directory: worker
- Health Check Path: /api/health

A imagem usa fontes gratuitas de mídia e Edge TTS, sem chave obrigatória para o teste inicial.
