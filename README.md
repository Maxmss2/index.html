# VÍDEOCREATOR

Primeira versão do VÍDEOCREATOR: uma central para comandar agentes de criação de Shorts.

## V1
- Campo de comando
- Lista de agentes
- Histórico local de tarefas
- Estrutura preparada para conexão futura com IA, geração de mídia e APIs oficiais do YouTube

> A publicação e o acesso ao canal serão implementados usando autorização explícita e APIs oficiais.
